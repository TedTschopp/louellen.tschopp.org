# louellen.tschopp.org

A simple coming-soon page for Louellen.

Website: https://louellen.tschopp.org/

Hosted on GitHub Pages from the `main` branch, using the repository root. The site is plain HTML and CSS; it has no package dependencies or build step.

Edit `index.html` to change the page. Keep `CNAME` and `.nojekyll` in the publishing root. The Cloudflare DNS CNAME points to `tedtschopp.github.io`.
